# Agentroid 1.0.0

Agentroid lets an AI agent such as Claude Code drive a real Android phone or an emulator over adb. It is an MCP server plus a small daemon on your Windows PC, and the safety checks run in the daemon, outside the model.

This is the first tagged release. "1.0" is a promise about the interface: the 27 tool names and their inputs, the result shape (`ok`, `data`, `error`, header, receipt) and the 13 error kinds change only in a new major version. It is not a claim that every part is finished; the limits are below.

## What is in it

- **27 MCP tools** over stdio: 23 device tools (read the screen as a short text list, tap, type, swipe, scroll, open apps and URLs, read-only diagnostics, copy files) and 4 job tools that run several steps on the PC in one call. A `minimal` profile lists 8 tools. An optional HTTP listener serves a tailnet with one token per device and mode.
- **Small looks at the screen.** On one recorded home screen the default answer is 229 tokens, against 11,565 for Android's raw screen description (measured on 14 Nov 2026; see the README for the method).
- **Safety in the daemon.** A device allowlist, a deny-by-default adb guard, device modes, a screen guard that refuses payments, banking apps, factory resets and password fields and asks before send, delete, install and permission dialogs, and a hash-chained audit log. The red-team results and the known misses are in `SAFETY.md`.

## Changed since the 0.1.0 preview

- Typed errors: each error kind has a documented meaning and retry rule, and start-up errors have stable codes (`config`, `bind_refused`, `token`, `credstore`).
- An error result's text names its run id, so a refusal can be matched to its receipt.
- docs/REFERENCE.md now lists every tool, error kind and environment variable, and the tests fail when the docs drift from the code.
- CI runs the whole Rust workspace on Linux as well as Windows, and checks that a release tag matches every version in the repository.

The full list is in `CHANGELOG.md`.

## Limits

- The daemon runs on **Windows only** (tested on Windows 11).
- Build from source: nothing is published to crates.io or npm. The zip below holds the Windows binaries and the MCP server's source (run `npm ci` in its `mcp` folder).
- The agent gets text, not images: `screenshot` and `look` send no image bytes.
- `pixel_probe`, and `look`'s `element` and `ocr` options, are not implemented.
- On the stdio path every allowed phone runs in `full` mode.
- Claude Code is the only MCP client tried.

## Checking the download

`SHA256SUMS.txt` holds the SHA-256 of the zip. In PowerShell:

```powershell
(Get-FileHash .\agentroid-v1.0.0-windows-x64.zip -Algorithm SHA256).Hash.ToLower()
```

The result should equal the first field of `SHA256SUMS.txt`.
